# Event Management Platform

## Project Overview

This is an Angular standalone application developed as part of a hands-on project.

The application allows users to:

- Browse available events
- View event details
- Book event tickets
- Manage bookings
- Toggle between Light and Dark themes



## How to Run

Install dependencies:

```bash
npm install
```

Start the Angular application:

```bash
ng serve
```

Open your browser:

```
http://localhost:4200
```
