# Event Management Platform

## Project Overview

This is an Angular standalone application developed as part of a hands-on project.

The application allows users to:
- Browse available events
- Search events by title
- Filter events by category, date, and price
- Sort events by date and price
- View event details
- Book event tickets
- Manage bookings
- Cancel bookings
- Toggle between Light and Dark themes


## Technologies Used

- Angular 19.2.0 Standalone Components
- TypeScript
- HTML5
- CSS3
- MockAPI (REST API)
- Vercel Deployment

## How to Run

Install dependencies:

```bash
npm install
```

Start the Angular application:

```bash
ng serve
```

Open your browser:

```
http://localhost:4200
```
